Detection rules Turning a rule off stops it being evaluated at all. A rule that is on either blocks — it stops the call — or reports it and lets it through; which one is decided by the policy's enforce selection, not by these toggles. Core safety-floor rules stay pinned on even if a project tries to disable them. Saved to .prismor/policy.yaml; live agents pick it up within 30 s.
